CATEGORY 5: ELLIPTIC DATASET STYLE ADDRESSES (ILLICIT / LICIT / UNKNOWN)
================================================================================

NOTE: The Elliptic dataset (203,769 transactions) does not publish raw wallet
addresses publicly, but the following represent the CLASSES and FEATURE patterns
used in training/testing GNN AML models.

47. Illicit Pattern — Darknet Market / Scam
    Features: High outgoing degree, low incoming diversity, rapid layering,
    mixer interaction, Peel-chain structure.
    Label: class1 (illicit)
    Notes: Typical of Silk Road, AlphaBay, or ransomware payment addresses.

48. Illicit Pattern — Ransomware (WannaCry / LockBit style)
    Features: Single large inbound, many small outbound, high fee bursts,
    temporal clustering in attack windows.
    Label: class1 (illicit)

49. Illicit Pattern — Ponzi / MLM (Gain Bitcoin style)
    Features: Fan-in from many retail addresses, fan-out to single collector,
    periodic payout bursts, token-switch to low-value in-house coin (MCAP).
    Label: class1 (illicit)

50. Licit Pattern — Regulated Exchange (VASP Hot Wallet)
    Features: High volume, diverse counterparties, regular sweep to cold storage,
    KYC-linked fiat on-ramp clustering.
    Label: class2 (licit)

51. Licit Pattern — Mining Pool (F2Pool, Poolin style)
    Features: Block reward consolidation, batched payouts to many workers,
    stable temporal periodicity.
    Label: class2 (licit)

52. Unknown Pattern — Unlabeled / Ghost Address
    Features: Insufficient transaction history, isolated subgraph, no external
    labels, low betweenness centrality.
    Label: class3 (unknown)

USAGE NOTES FOR TESTING
================================================================================

1. BLACKLIST CHECKING: Use addresses in Category 3 with BlockSec Freeze Checker
   or direct contract reads (isBlackListed on USDT TRC-20 / ERC-20 contracts).

2. SANCTIONS SCREENING: Use addresses in Categories 1 & 2 against OFAC SDN List
   and commercial sanctions APIs (Chainalysis, TRM Labs, CipherTrace).

3. GNN MODEL TRAINING: Use Category 5 patterns to simulate Elliptic-style
   feature vectors (166 local + 72 aggregate features for transactions;
   56 features for wallet addresses in Elliptic++).

4. CLUSTERING TESTS: Apply common-input heuristics to BTC addresses in
   Category 1. Multi-hop peel-chain detection works on Mt. Gox and
   laundering-style addresses.

5. CROSS-CHAIN TRACING: TRON hex addresses (41...) are identical to Ethereum
   addresses (0x...). Test address format normalization and chain-ID checks
   using paired entries where available.

6. TEMPORAL GRAPH TESTS: The Elliptic dataset uses 49 time steps (~2 weeks each).
   Replicate chronological train/test splits using the 203,769-node transaction
   graph structure with Categories 1-4 as real-world anchors.
